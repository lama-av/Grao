# 14 · Roteiro do teste com 3 pessoas (v0.8, #058)

**Objetivo (doc 10, v0.8):** alguém que nunca viu o Grão consegue animar um loop em 2 minutos, sem explicação.
**Quem:** 3 pessoas de fora (colegas da ESPM), de preferência uma que anima, uma que ilustra e uma que não desenha.
**Quem aplica:** o Raphael. O VS Code não tem como fazer este teste; o roteiro fica pronto para usar.

## Antes

- Tablet carregado, Grão instalado, **dados do site limpos** (para abrir o projeto de boas-vindas e as dicas).
- Celular filmando as mãos e a tela (com autorização da pessoa).
- Não explicar nada além da frase de abertura. Responder perguntas com "o que você tentaria?".

## Frase de abertura

"Isto é um caderno de animação com cara de impressão riso. Quero ver como você usa. Pense em voz alta."

## Tarefas (cronometrar cada uma)

| # | Tarefa dita à pessoa | Sucesso quando | Tempo | Ajudou? | Observação |
| --- | --- | --- | --- | --- | --- |
| 1 | "Faça um risco na tela." | Desenhou com a caneta | | | |
| 2 | "Pare a animação." | Tocou no centro da roda ou segurou o prato | | | |
| 3 | "Desenhe uma bolinha que se mexe em 4 frames." | Loop com 4 desenhos diferentes tocando | | | |
| 4 | "Troque a cor de uma tinta." | Usou a pétala Camadas (arco de cores) | | | |
| 5 | "Desfaça o último risco." | Desfazer na roda ou 2 dedos | | | |
| 6 | "Pinte o miolo da bolinha com outra cor." | Balde em outra camada | | | |
| 7 | "Guarde isso num arquivo." | Menu → Salvar arquivo | | | |
| 8 | "Mande isso para um amigo como GIF." | Exportar → GIF | | | |

## Perguntas no fim (1 a 5)

1. Foi fácil saber onde estavam as coisas?
2. A roda do canto ajudou ou atrapalhou?
3. A cara de riso (grão, cores) agradou?
4. Algum toque fez algo que você não esperava? Qual?
5. Usaria para animar de verdade? Por quê?

## Depois (para o chat)

- Lista de problemas com prioridade P1/P2/P3 (P1 = travou a tarefa).
- Tempos médios por tarefa; tarefas com ajuda.
- Toques acidentais (palma, 2 dedos) que viraram ação.
- Levar para a auditoria da v0.8 no chat.
